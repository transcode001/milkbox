# Milkbox Docs

Next.js documentation site for Milkbox.

## Development

From the repository root:

```bash
pnpm dev:docs
```

Or from `apps/docs`:

```bash
pnpm dev
```

Open [http://localhost:3001](http://localhost:3001) in your browser.

## Building

From the repository root:

```bash
pnpm --filter docs build
```

## Quality Checks

```bash
pnpm --filter docs lint
pnpm --filter docs check-types
```
