# Milkbox Web

Next.js web application for Milkbox.

## Development

From the repository root:

```bash
pnpm dev:web
```

Or from `apps/web`:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Building

From the repository root:

```bash
pnpm --filter web build
```

## Quality Checks

```bash
pnpm --filter web lint
pnpm --filter web check-types
```
